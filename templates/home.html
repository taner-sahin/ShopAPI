Roller & Permissions

Authentication tek başına yeterli değildir. Kullanıcıların hangi kaynaklara erişebileceği permission katmanında kontrol edilir.

👤
NORMAL USER

Kullanıcı

  • ✓ Ürünleri görüntüleyebilir
  • ✓ Kategorileri görüntüleyebilir
  • ✓ Sipariş oluşturabilir
  • ✓ Kendi siparişlerini görüntüleyebilir
  • ✓ JWT ile korunan endpoint'lere erişebilir
  • × Başka kullanıcının siparişine erişemez
🔒 Ownership / User Isolation
🛡️
STAFF USER

Admin

  • ✓ Product CRUD işlemleri
  • ✓ Category yönetimi
  • ✓ Sipariş yönetimi
  • ✓ Yönetim endpoint'lerine erişim
  • ✓ Staff permission kontrolleri
🛡️ Role Based Permission
